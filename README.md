# arduino

Desk Display was my first project. It includes code for a display that gives a water count, a Tasks Done tracker, and a temperature gauge

Wrist Component is the first part of the Sync Machine, it handles button inputs, swithces metronome modes, displays everything on an 0.96 OLED, and handles the vibration motor

Ankle Component is the second part of the Sync Machine, it handles accelerometer readings, sonar readings, and does the math... then it passes whether a step was taken to the Wrist Component
